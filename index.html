This system operates with display and data-tagging only. There is no auto-conversion or simulated exchange rates between currencies. Every transaction amount is stored and shown exactly as entered.

• Base Currency: Used as the default preselected currency for new transactions and accounts.

• Honest Accounting: Subtotals never mix different currencies into an artificial 1:1 total. When a category or report contains multiple currencies, subtotals are broken down per currency.

Transactions and accounts tagged in currencies other than the base currency will display a distinct currency badge.
